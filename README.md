# PRAGATI · apprentice record (prototype)

**P**erformance & **R**ecords of **A**pprentices: **G**rowth, **A**ttendance, **T**raining, **I**ntegrity.

Static prototype with sample (fictional) data. Open `index.html` for all portals; every demo account uses the password `Demo@123`.
Portals share state through the browser's localStorage, so open them as tabs in the same browser.

- `assets/data.js`: parameters (11, PQCDSM), Likert statements, kaizen model, sample seed, scoring rules
- `assets/views.js`: screens
- `assets/app.js`: login, routing, actions, store
- `assets/pragati.css`: light theme in Bajaj blue
